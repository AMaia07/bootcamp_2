# Pokédex Web
## Autor
Artur Maia de Morais — Matrícula 22610962
## Descrição
Aplicação web que busca Pokémon pelo nome ou número e exibe imagem, altura,
peso e tipos. Útil para fãs consultarem rapidamente dados de qualquer Pokémon.
## API utilizada
- PokeAPI — https://pokeapi.co/docs/v2
- Endpoint consumido: `https://pokeapi.co/api/v2/pokemon/{nome-ou-id}`
## Funcionalidades
- Busca por nome ou número (botão "Buscar" ou tecla Enter)
- Exibição de imagem, número, nome, altura (m), peso (kg) e tipos
- Mensagens amigáveis para busca sem resultado e falha de conexão
## Como executar localmente
